## 0. Design Read

> 本地 AI 工具配置**控制台**（single-user 技术用户，中文优先，离线可用）。语言：冷灰控制台（白卡灰底）+ 品牌蓝动作色 + 数据密集纪律。气质：精确、克制、工程感；像一件仪表，不像一个营销页。动效短促缓出；零装饰动画；零外部字体依赖（离线可用是硬需求）。

## 3. 间距/圆角/阴影/动效

- **间距阶**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`（px）。区块间用 24/32，页面分节 48/64；卡内边距 16–24。
- **圆角**：chip/徽标 `4px`、控件 `6px`、内嵌面板/浮层 `8px`、卡/面板 `10px`、对话框/抽屉 `12px`；**禁 pill**（`radius.full` 只允许出现在 ≤24px 高的计数胶囊，且全站 ≤ 1 种）。
- **阴影**：卡片默认**无阴影**（靠灰白对比 + 1px 描边分层）；阴影只属于浮层，克制三档且一律 tinted（冷灰 alpha ≤0.14）——下拉/菜单取 `shadow.sm`、对话框/抽屉取 `shadow.md`、命令面板取 `shadow.lg`（仅浮层允许；**禁**纯黑低透明大投影）。
- **动效**：交互反馈 `120–160ms cubic-bezier(0.2, 0, 0, 1)`；进入/展开 `220ms`；**禁**线性/ease-in-out 默认曲线、禁装饰性循环动画；`prefers-reduced-motion` 下一律降为无动画（≤0.01ms）。

## 4. 布局原则

- **首屏即工作台**：`/` 直接 `Navigate /usage`（无登录门、无工具矩阵页）；顶部健康条与诊断入口保留（原 UC-035 A4 工具矩阵/五路由状态已随工作台删除）。
- 网格对齐：数据区一律网格/表格对齐；数字右对齐 + tabular-nums。
- 响应式：`≥900px` 双栏（侧栏 216px + 内容）；`<900px` 导航抽屉 + 单列（承 UC-020 A4/A5 键盘与抽屉契约）；主内容永不水平溢出。
- 侧栏为**平铺一级导航**（2026-10 清理后）：NAV 六项 = 请求映射 `/arms` → 用量 `/usage` → 用户 `/users` → 诊断 `/diagnostics` → 系统 `/system` → 设置 `/settings`（`app/routes.tsx` `NAV`，键 `nav.router/nav.usage/nav.users/title.diag/nav.system/nav.settings`）；字号一级 `fontSize.nav`（14）。原多级目录（配置切换组、工具二级项、`/arms?view=` 深链组头、WorkBuddy 项）已随工具页/工作台删除。
- 高度用 `min-height: 100dvh` 语义，禁 `100vh` 满屏区块。
- 留白优先于分隔线：优先用间距分层，其次 1px `border.default`（分割线用 `border.divider` alpha），禁止双线/多框嵌套装饰。

## 5. 组件行为（关键项）

- **主按钮**：品牌动作蓝底（`brand.action`）白字；一屏至多 1 个主按钮（其余为次按钮/文字钮）。
- **次按钮**：白底、`border.control` 描边、正文色字。
- **危险动作**：pale red 文字/描边；确认对话框内主按钮可为 `danger` 深字底。
- **状态徽标**：`status.*.bg` 底 + `status.*.fg` 深字 + 4px 圆角 + 11px/500（sm 档高 20 / md 档高 24）；不用图标代替文字语义（图标可作前缀）。
- **表格**：表头 `bg.base` 底 + 11px 全大写小标签；行 hover `fill.hover`（alpha 叠加）；行高 **40–56px**（UC-099 契约；2026-09-28 R211 修正，旧的 ≤40px 密集值废止）。
- **行高与点击目标分别量测**（UC-099 新段口径）：行高 = **整行布局高度**（配置表 40–56px，见 §9）；点击目标 = **实际可命中的区域**（按命中测试实测量，不看视觉尺寸）。44×44px 只约束**触屏主动作**，不强制桌面鼠标控件同尺寸；触屏布局须容纳目标区，且目标区不得重叠相邻操作。
- **空/错误/加载**：三态各有一行**可读文案 + 一个恢复动作**；骨架屏仅用于 ≤2 处首屏区块（静态灰块，无 shimmer）。
- **命令面板**（⌘K）：顶部居中、宽 560px、白卡、无遮罩模糊（用 `fill.scrim` `rgba(20,23,28,0.45)` 平遮罩）；键盘全操作。

## 9. 配置管理表格与固定启用列（UC-039）

> **范围标注（2026-10-14）**：本节原描述的 `/tools/:id` 配置管理区（及「三个入口」的配置详情/请求详情真链接）已随工具页删除；行高、列宽、省略与搜索/排序契约作为**通用数据表纪律**继续适用于保留数据表（usage/users/system 等），机器判据 `e2e/uc099-density.pw.ts` 若在册则仍有效。

工具页（`/tools/:id`，**已删除**）的**配置管理**区曾是数据表（不是卡片列表）：表头沿用 §5 的 `bg.base` 底 + 11px 全大写小标签。
列序固定为 **名称｜类型｜模型｜状态｜操作｜启用**；类型列用 `profiles.kind.*` 的新术语（官方 / 受管 / 请求映射派生 / 下发 / 自建），
**官方行不渲染模型**（UC-037 A2：它是工具的原生形态，没有渠道模型，不许拿策略默认值冒充）。

- **固定启用列**：最后一列（含列头）`position: sticky; right: 0`，**必须有不透明底**——`color.surface`（当前生效行与其 hover 用 `color.surfaceSubtle`，与既有代码的行 hover 叠加色差 ≤1/255）。透明底会让横向滚过的单元文字从下面透出来。
  表格用 `border-collapse: separate; border-spacing: 0`（合并边框在部分浏览器会吞掉固定列的边框），外层是 `TableScroll`（横向滚动容器，最小表宽 880px）；窄视口下横向滚动而**启用列不随内容滚走**（375px / 1280px 双验）。
- **行高预算 40–56px**（UC-099 契约「整行布局高度」；2026-09-28 R211 修正，旧的 ≤40px 密集值废止）：行内动作一律 `size="small"` 文字钮；**点击目标（实际命中区）与行高分别量测**——行高 48 给 44px 触屏目标区留出行内余量，目标区不重叠相邻行（§7）。
  行高**不交给内容长度**（2026-09-28 C-5 lane 实测回填）：名称与复制来源提示**单行省略**（`text-overflow: ellipsis` + `title` 给全名，完整文本仍在无障碍树）；模型列**不折行**（横向不够由 `TableScroll` 局部横滚承载）；桌面（≥900px）操作列**单行排布**（6 枚按钮换行会把行顶到 ~71px），窄屏（<900px）恢复换行且行高区间不适用（表格本就局部横滚）；单元竖向内距 4px（两层徽标的状态列 ≈52px，6px 会把它顶到 56.4px）。行高的机器判据在 `e2e/uc099-density.pw.ts`。
- **搜索与排序**（UC-099 A4，2026-09-28 C-5 lane）：区块工具条给「搜索配置」**提交式**自由文本筛选（Enter / 「搜索」，`?q=`）；名称与类型列头是排序控件（`aria-sort` + `TableSortLabel`，`?sort=name|kind&dir=`，`asc` 省略；**三态循环：升序 → 降序 → 默认展示序**）；两者**只作用于展示**，不改服务端卡序、不发写请求；过滤零命中给可读文案 + 清除动作（五态纪律）。
- **三个入口**：配置详情 / 请求详情是**真链接**（`/tools/:id/configs/:pid[/requests]`，`target="_blank" rel="noopener"`；可访问名带配置名与「新标签页」），测试是**按钮**（非导航）。
- **测试的禁用与状态**：禁用（本机未安装 / 家族无测试配方）时给**可见原因**（表格下方唯一一处说明，按钮以 `aria-describedby` 指过去），不做哑灰按钮、不隐藏入口。结果对话框三态：运行中（明说真调本地 CLI、最长 90 秒）/ 结果（status、耗时、模型、CLI、退出码、原因、输出摘要）/ 失败（错误码文案 + 重试；客户端 100s 兜底超时另给专门文案）。
- **token 用法**：sticky 底与边框只用 `color.surface` / `color.surfaceSubtle` / `color.border`；间距只用 `spacing.*`；输出块用 `color.surfaceSubtle` + `radius.chip`。不新增色值、不引入第二种 accent。

## 10. 请求映射页的列表展示排序（UC-096 A7）

请求映射页（`/arms`）的两张列表给**纯展示排序**（2026-09-28 C-6 lane；取代 C-1 期「无该能力」的登记）：请求映射（源规则）列表按**名称**，每条请求映射的模型映射表按**别名 / 目标**两列（列头是排序控件）。

- **URL 契约与配置表同款**（§9）：`?sort=name|alias|target&dir=desc`；`asc` 是默认方向、规范 URL 省略；控件是**三态循环**——升序 → 降序 → 默认序（排序键从 URL 删掉）；非法值与孤儿 `dir` 载入即 **replace** 归一（不新增历史条目），硬刷新与 Back/Forward 恢复同一顺序。
- **控件形态**：工具条上是「排序 名称 ⇅」小按钮（可访问名带当前状态「未排序/升序/降序」，右侧状态条 `aria-live` 播报「已按「X」Y 排序」）；映射表列头是原生按钮 + 方向图标，`aria-sort` 如实标当前列（未排序列 = `none`）。全部键盘可达（Enter/空格切换键与方向）。
- **只作用于展示（不可协商）**：排序不写回规则、不改服务端回读序、不发写请求；不改变精确匹配与请求去向，也**不新增执行优先级**——状态条常驻写明「仅展示顺序：不写回规则，不改变匹配与请求去向」。不变式对照（排序前后配置哈希 / 规则条目 / 桩上游收到的 model·effort·端点一致）在 `e2e/arms-sort.pw.ts`。

## 11. 本机诊断（UC-100，C-7 lane）

**本机诊断统一面**（`MachineDiagnostics`，路由 `/diagnostics`）读同一份只读快照（`GET /api/v1/diagnostics`；契约见 `doc/api-v1.md` §16）。（工具页的 `ToolEndpointCompare` 端点对照已随工具页删除——2026-10 清理。）

- **信息层级**：区块头 = 「本机诊断」+ 检测态徽标 + 计数 chip（异常 / 未证实 / 正常，逐项独立计数——正常项不被失败项拖累）+ 「最近检测：{时间}」+ 「检测预算 10 秒」+ 右端 [重新检测] [复制诊断包]。正文先「全站与网关」组（代理离线 / 上游鉴权 / 上游限流），再「按工具」组（每工具三条：未安装 / 版本未知 / 配置不可读）；每行 = 状态徽标 + 类目 + 工具链接 + 陈旧徽标 + 作用范围 / 观测时间 / 操作编号（mono）+ 事实说明 + 可行下一步（路由链接或说明）+ 非正常项的 [查看建议修复]。
- **安装类负值的回填窗守卫**：原 `lib/probeBackfill` 共享守卫已随工作台/工具详情页删除（2026-10 清理）；诊断面按上一条「检测态语义」如实呈现探测结果，未确认负值计入「未证实」而非「异常」的口径不变。
- **检测态语义（A4，不可协商）**：>1s 在飞 = 「检测中（已 ×s）」+ 慢说明 + 当前阶段；预算耗尽 = 警告条给**原因 + 阶段 + 重试**；在飞或超时期间**旧值保留并标陈旧**——`stale` 时条目带「陈旧」徽标且 `ok` 状态降级为中性色（`itemTone`），**不继续显示为当前正常**。
- **环境覆盖对照（A3）**：`envOverrides` 行把「运行时（生效）」与「盘上（写入）」并列（mono，任意断点可换行），`observed !== expected` 时挂「冲突」徽标并给一口径说明（「以运行时为准，盘上判定并未实际生效」）；未检测/未完成时显示**未确认**，不声称「没有覆盖」。工具页区块补「最近一次实际请求观测（运行时验证证据）」与「盘上决定键」两行并列。
- **诊断包复制（A6）**：复制的是**服务端已脱敏**的 `GET /diagnostics/bundle` 序列化（两空格缩进 JSON），客户端不二次拼装；无可用内容（从未检测）时复制钮禁用并以 `title` 说明。
- **服务离线（A5）**：任一只读面出现「请求没到服务端」的失败即进入离线面：危险条给「本地服务离线」+ [重新连接]（重试四个外壳段 + 重取两个诊断面 + 清本地探测失败记录）；**修复入口禁用**并给 `title` 原因；断连前预取的诊断包保留并可继续复制（可访问名写明「保留的」）。
- **建议修复（A7）**：`fix/preview` 计划面在对话框里呈现（可行 / 是否写盘 / 动作清单与参数 / 恒显的「取消不改变任何文件；诊断与修复都不安装依赖，也不会自动修复」承诺）；动作去向：`transaction` 恢复/重置进入**既有** `ToolActionDialog` 事务（取消 = 零变化）、`action` 启动代理**点击即显式确认**（本弹窗即预览）、重检测回到面板发起、`journey` 进既有界面入口、未知 kind 原样展示不给按钮。
- **恢复对照（A8）**：一次面板内重检测完成后，给「逐项恢复对照（上次检测 → 现在）」表（检查项 / 上次 / 现在 / 结论）；结论逐态穷举——已消除（fail→ok）、**现已证实为正常（unknown→ok，此前未证实，不落「未证实（无变化）」兜底）**、新出现异常、仍异常、**未证实（保持未知）**（after=unknown 恒给「未证实（保持未知）」文案，不因一次成功全绿）、正常（无变化）。
- **token 用法**：只引用 `theme` 导出（`color` / `spacing` / `fontSize` / `fontFamily`）；表格沿用 §9 的 `bg.base` 表头与 1px 边界；不新增色值；375px 下长路径一律 `overflowWrap: anywhere`（`e2e/diagnostics.pw.ts` 的 375px 断言）。
